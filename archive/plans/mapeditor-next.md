## 1. 확정된 디자인/구조 결정 (재논의 불필요)

### 레이아웃
- **좌측 창고 패널이 화면 좌측 전체 세로**를 차지. 즐겨찾기·캔버스·툴바·하단바는 전부 **그 오른쪽
  영역 안에서만** 존재(즐겨찾기가 좌측 패널을 가리지 않음). 좌측 패널을 접으면 오른쪽 영역 전체가
  넓어짐.
- **색 없음**(검정 배경 + 흰 테두리만) — 디자인은 나중, 지금은 기능/레이아웃 검증 단계. **예외**:
  카테고리 대표색(카드 배경 반투명 틴트)은 도입됨(아래 카드 절 참조).

### 모션
- 각 패널이 **자기 붙어있는 화면 가장자리에서 스프링으로 등장**: 좌측 창고=왼쪽, 즐겨찾기=위,
  하단바=아래, 우측 툴바=오른쪽, 캔버스=중앙 스케일. 토큰: `motionTokens.ts`
  (`springPop = {stiffness:500, damping:28}`, 스태거 0.05s/패널).
- `mapedit`로 닫으면 **같은 방향으로 역재생** 후 실제 언마운트(`CLOSE_SETTLE_MS=480ms` 대기).
- 패널 폭/높이 변화(접기·리사이즈)도 스냅 아니라 스프링. 단, **`layout`(FLIP) 프롭은 즐겨찾기
  높이엔 쓰지 않음** — 좌측 패널 폭 변화 때마다 즐겨찾기 높이가 덩달아 흔들리는 버그가 있어서,
  실측 높이(ResizeObserver)로 직접 `animate` 하는 방식으로 교체함(`FavoritesPanel.tsx` 참조).

### 카테고리
- UI 필터 그룹 4종: **블록**(장치 obstacle + 지형 platform 통합) / **적군** / **아이템** / **배경**.
  실제 스키마 카테고리(obstacle/platform)는 `PlaceholderCard.category`에 보존, 필터는 `group`으로만.
- 대표색·아이콘은 **임의 지정**(`testData.ts`의 `CATEGORY_COLOR`/`CATEGORY_ICON`) — 나중에 실제
  브랜드/디자인 확정 시 교체 대상.

### 카드 (`CategoryCard.tsx` — 창고·즐겨찾기 공용)
- **정사각형**, 카테고리 대표색의 **옅은 반투명 배경**(나중에 실제 에셋 이미지가 들어오면 이 색이
  이미지 뒤 배경으로 남는 구조).
- **모서리**(우상단): 평소엔 **카테고리 아이콘**, **그 근처로 마우스를 가져가면**(카드 전체 아님)
  액션 버튼으로 전환 — 창고 카드="+"(즐겨찾기 추가), 즐겨찾기 카드="✕"(제거).
- **카드 전체에 마우스를 올리면** 즉시 상세 툴팁(라벨·카테고리·소유자) 표시.
- **소유자 표시**: 기본은 표시 안 함. **내가 만든 것만** 하단에 작게 "나의 에셋" 텍스트.
- 텍스트 라벨(개별 이름)은 카드에 안 보임 — 툴팁에서만.

### 좌측 창고 패널 (`WarehousePanel.tsx`)
- **조회 전용** — 선택 불가. "+즐겨찾기"로 꺼내야 실제 붓(즐겨찾기)에서 선택 가능.
- 검색 없음(2026-07-14 확정 — 어차피 개수 제한이 빡셈).
- **별도 축 2개**: 내가만든/남이만든 2단 토글 + 카테고리 탭(전체/블록/적군/아이템/배경, 단일선택).
  둘 다 동시 적용.
- 카드가 정사각형이라 폭에 따라 **그리드로 줄바꿈**(flex-wrap).
- **리사이즈**(안쪽 테두리 드래그) + **접기**(가장자리 중앙 원형 화살표 ◀/▶, 접으면 얇은 탭).
- **최소 폭**: 카드 1개가 여유롭게 보이는 크기까지만(`LEFT_PANEL_MIN = FAV_CARD_SIZE + PAD*2 + 20`,
  `sizeTokens.ts`).

### 즐겨찾기 패널 (`FavoritesPanel.tsx` + `FavoriteGroupBox.tsx`)
- **"이번 판 실사용 슬롯"**(게임 규칙: 내가 만든 것 최대 3종 + DB 카테고리별 정해진 개수 랜덤 —
  ⚠️ 이 상한은 **아직 UI에서 강제 안 함**, 지금은 무제한 추가 가능).
- **카테고리별 구획**(테두리 없이 간격으로만 구분 — 그룹 박스 자체 테두리는 카드 라운드와 겹쳐
  선이 깨지는 버그가 있어 제거함), 구획 폭은 개수에 비례(`layout` FLIP으로 스프링 전환).
- **리사이즈 없음** — **접기(1줄)만**. 접힘 높이 = 카드 한 줄이 안 잘리는 고정값
  (`FAVORITES_ONE_ROW_HEIGHT`, `sizeTokens.ts`).
- **같은 그룹 내 드래그 재정렬** — **dnd-kit**(`@dnd-kit/core` + `sortable`, `rectSortingStrategy`)
  사용. ⚠️ **framer-motion `Reorder`는 1축(한 줄) 전용이라 여러 줄로 감싸지면 위치 계산이 깨짐** —
  이게 dnd-kit로 교체한 이유. 다른 드래그 재정렬 필요한 곳이 생기면 dnd-kit 우선 검토.
- **접힘(1줄) 상태에서 재정렬**: `FavoriteGroupBox`가 `ResizeObserver`로 실제 컨테이너 폭을 측정해
  "윗줄에 정말 들어가는 개수"만 렌더링·재정렬 대상으로 삼음 — 아랫줄(가려짐)은 DOM에 렌더 자체를
  안 해서 드래그 판정에서 완전히 배제.

### 우측 툴바 (`Toolbar.tsx`)
- **감싸는 테두리·배경 없음** — 정사각형 버튼만 공중에 떠 있음. 고정폭, 리사이즈·접기 없음.
- 남는 세로 공간 안에서 **가운데 정렬**.
- 실제 도구 구성은 **미확정** — 지금은 placeholder 3개(선택/지우개/이동)로 **배타적 단일 선택**
  메커니즘만 검증(하나 고르면 이전 것 해제, 흑백 반전으로 최소 표시).

### 맵 캔버스 (`MapCanvas.tsx`)
- **박스 아님** — 다른 패널·버튼에 가려지는 공간 외 **전체가 편집 영역**.
- **휠 스크롤 = 커서 기준 확대/축소**(0.5배~3배 제한, `sizeTokens` 아님 — 이 파일 상단 상수).
- **우클릭 드래그 = 팬**(이동), 팬 범위는 **맵 크기 기준으로 제한**(뷰포트보다 맵이 크면 맵 안에서만,
  작으면 맵이 화면 밖으로 안 나가게).
- **테스트 격자**: 40타일(가로) × 20타일(세로), 48px/타일(`EDITOR_TILE_PX`) — 실제 게임 tileSize와
  무관한 에디터 전용 값(에디터도 나중엔 게임 tileSize를 따라가야 할 수 있음, 지금은 검증용 고정값).
- 배치 로직(에셋 놓기) **미구현**.

### 스위치 (게임 규칙 — 참고용, 에디터엔 아직 미반영)
- 라인당 boolean 1개(전역), OFF 시작, 서버 권위. 토글러는 **유저 에셋에 붙는 옵션**(시스템 블록
  아님). 상세는 `docs/KJH/visual-language.md` "스위치" 절.

## 3. 남은 작업 (우선순위 순 아님 — 다음 논의로 정할 것)

- **배치 로직**: 캔버스 클릭으로 에셋(즐겨찾기에서 선택된 붓) 놓기. 좌표는 `MapCanvas`의
  `pan`/`zoom`으로 화면→월드 좌표 변환 필요. 1타일 스냅.
- **flipX**(좌우반전), **patrol/ride 끝점 핸들** — 배치 결정 사항(이전 세션에서 확정, 아직 미구현).
- **깃발**(시작/끝) — 게임 규칙 문서(`docs/KJH/screen-design.md` "라인·깃발" 절) 참조: 미리 배치,
  3×1 바닥 세트, 끝<시작 금지, 자유 이동(가로·세로).
- **[테스트하기] 버튼 로직** — 지금은 정적. 자기 라인 단독 플레이 테스트 + 성공 시 MapLine 저장
  (MapLine 스키마는 확정됐으나 `schema.prisma` 반영·마이그레이션 아직 — VPN 배포 세션 필요).
- **실제 에셋 이미지** — 지금은 카테고리색+아이콘뿐. 실제 스프라이트 파이프라인(AssetSprite) 연동.
- **즐겨찾기 상한 강제** — 내 3종/공용 카테고리별 개수 제한이 UI에서 아직 안 걸림(무제한 추가 가능).
- **저장 API** — 전무. 지금은 zustand 메모리에만(새로고침하면 소실). 패널 크기/접힘만
  localStorage로 남음.
- **우측 툴바 실제 도구** — 아직 뭐가 필요한지 미정(당신이 고민 중이라던 부분).

## 4. 주의사항 / 게이트웨이

- **`commands.ts`, `client/src/audio/`, `client/src/fx/`는 다른 병렬 세션(사운드/이펙트 담당)이
  동시에 작업 중** — 이 파일들 건드릴 땐 전체 재작성 말고 최소 diff로.
- **`.claude/launch.json`의 `client` 설정(포트 5173)은 다른 세션이 씀** — 이 mapeditor 세션은
  `client-alt`(autoPort)로 검증했음. 필요 시 재사용.
- **미커밋 상태** — 다른 계정/세션에서 이어가려면 이 워킹트리를 그대로 가져가거나(같은 로컬 repo),
  커밋해서 넘겨야 함. 지금은 커밋 안 함(요청 없었음).
- **instakill 제거**(별개 작업, 이미 완료) 등 이전 세션 변경사항과는 무관 — 이 문서는 맵 에디터
  UI 셸 범위만 다룸.
