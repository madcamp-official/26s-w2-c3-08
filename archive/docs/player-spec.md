# 플레이어 사양 (2026-07-10 확정분)

## 스프라이트

- 캔버스 규격 **1×2 타일** (64×128px, 타일 64px 기준). 유저 제작 아바타도 이 규격으로 생성.
- **히트박스: 키 자동 보정 (2026-07-10 개정 확정 — 이전 2단 티어안 대체)**:
  - 그린 그림의 불투명 영역 높이에 따라 키가 **1.65~1.95타일(105~125px) 범위로
    자동 클램프** (AI 생성 완료 시 알파 바운딩박스로 산출)
  - 범위를 좁게 잡아 "작게 그릴수록 유리" 공정성 문제를 ±9% 이내로 제한
  - 자유 수치 입력 없음. 웅크리기 시각 높이는 키와 무관하게 **0.95타일 고정**
- **웅크리기 연출 (2026-07-10)**: 총 키 0.95타일로 압축. 상체 62% / 하체 38%
  배분 — 하체가 더 많이 줄어듦
- **슬라이딩 가속 (2026-07-10)**: 3200px/s² — 한계속도(520px/s) ~0.16초 도달
  (수치는 스파이크 실험값, 밸런스 조정 대상)
- 애니메이션: idle / walk / onair 3종 (AI 생성).
- **스쿼시 연출**: 스프라이트를 세로 중앙 가로선으로 상체/하체로 나눠,
  상황에 따라 상체(또는 전체)의 세로 스케일만 코드로 변형한다.
  스프라이트 추가 생성 없이 상호작용을 시각화하는 장치.
  - 점프/착지: 상체 눌림→복원
  - 웅크리기: 전체 위아래로 눌림
  - **밟힘: 상체 눌림 연출 — 디메리트 판정과 무관하게 항상 재생**
    (판정에서 밟힘 무효가 되어도 시각적 피드백은 보여줌)

## 조작

| 입력 | 동작 |
|---|---|
| A/D 또는 ←/→ | 좌우 이동 |
| Space | 점프 |
| S 또는 ↓ (지상) | 웅크리기 — 상하로 눌리고 이동속도 감소 |
| S 또는 ↓ (공중) | 내려찍기 |

### 내려찍기 (Ground Pound)
- 발동 즉시 **좌우 가속 무조건 0** (어떤 경우에도. 다른 플레이어에게 절대 밀리지 않음)
- 바닥에 닿을 때까지 수직 낙하
- 착지 지점이 경사면이면 **슬라이딩**으로 전환

### 슬라이딩
- 평평한 지형에 닿기 전까지 유지
- 슬라이딩 중 유효 입력은 **점프뿐** (다른 키 무시)
- 슬라이딩 중 점프: 좌우 가속을 유지한 채 슬라이딩 취소 + 점프

## 생명 체계

- 기본 생명력 **1** — 피해 = 즉사
- **거대버섯 효과** 보유 시 생명 +1 (총 2). 피해를 받으면 기본 상태로 복귀
- **낙사는 상태 무관 무조건 즉사** (거대버섯 무효)

## 사망·부활

- 사망 시 **현재 라인의 한 단계 아래(이전) 라인의 시작지점**에서 부활
- 첫 번째 라인에서 사망하면 첫 라인 시작지점에서 부활

## 플레이어 간 상호작용 (PvP)

- 플레이어끼리 물리 충돌 있음. **좌우로 서로 밀 수 있음**
  (예외: 내려찍기 중인 플레이어는 밀리지 않음)
- **머리 밟기** 가능 (마리오 방식). 밟힌 플레이어의 수직 속도 처리:
  - 상승 중이었으면 → 아래 방향 속도 n으로 **즉시 고정**
  - 하강 중이었으면 → 아래 방향 속도 n을 **추가**
  - ※ 기획 원문은 "가속도"로 표기했으나 물리 구현상 속도(velocity) 조작으로 해석.
    최종 용어 확정 필요 (아래 미확정 참조)

### 지연 보정 (밟기 판정)
- **밟는 쪽: 자기 클라이언트 화면 기준으로 무조건 성공** (favor-the-attacker)
  → 밟는 사람은 랙과 무관하게 손맛 보장
- **밟히는 쪽: 디메리트(하강 속도 부여) 적용 여부는 상대와의 지연시간 등을
  고려해 별도 판정** — 서버(또는 밟히는 쪽 클라이언트)가 중재
- 판정 결과와 무관하게 밟힘 스쿼시 연출은 항상 재생 (시각-판정 분리)

## 미확정

- [ ] 밟기 디메리트의 n 값 (속도인지 가속도인지 용어 포함)
- [ ] 밟히는 쪽 판정의 주체 — 서버 중재 vs 피밟힘 클라이언트 판정. 권고: 서버 중재
  (피해자 클라 판정은 치트·비대칭 이슈)
- [ ] 내려찍기로 몬스터를 밟았을 때 일반 밟기와 차이를 둘지 (예: 기절 무시 즉사)
- [ ] 거대버섯 효과의 크기 배율 상수 (스프라이트 1×2 규격 유지, 스케일만 확대 — 예: 1.25×)
- [ ] 웅크리기 상태의 히트박스 축소 여부 (연출만인지, 판정도 줄어드는지)
