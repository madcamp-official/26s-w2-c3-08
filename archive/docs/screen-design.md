## UI 테마 (2026-07-10 확정)

- **원칙**: "SMM2의 색과 격자 모티프를, 콘솔 런처의 그라데이션 질감으로 성숙하게
  렌더링". 유아스러운 표현(두꺼운 검정 아웃라인, 전면 도트 폰트, 원색 단색 면)은
  금지
- **색 배치 (SMM2 박스아트 기반)**:
  - 건설 노랑 `#F6BE00` = 주역 (타이틀 밴드·주요 버튼·활성 상태)
  - 스카이 블루 `#4A9DE0` 계열 = 배경 (수직 그라데이션)
  - 마리오 레드 `#E52521` = 포인트 (위험 액션·강조 숫자)
  - 지형 그린 `#43A047` · 흙 브라운 `#8B5A2B` = 보조
  - 정확한 hex는 구현 시 조정 가능한 기준값
- **질감**: 색면은 은은한 수직 그라데이션 + 부드러운 광택. 모서리는 살짝만 라운드.
  배치는 크고 밀도 있게 레이어드
- **타일 오버레이 (도트 감성의 핵심 장치)**: 면적 있는 색면(타이틀 밴드, 배경,
  큰 버튼) 위에 아주 투명한 흰색 선(rgba(255,255,255,0.08) 안팎)으로 타일 격자
  패턴을 일관 적용. 격자 크기는 인게임 타일과 호응(요소 크기에 따라 24~32px급).
  박스아트의 하늘 격자 모티프를 UI 전체 패턴 언어로 확장
- **폰트 이원화**: 타이틀·타이머 숫자 등 포인트 = 도트/블록형(Galmuri 큰 사이즈,
  OFL) / 본문·버튼·폼 = Pretendard
- **금지 목록**: 두꺼운 검정 픽셀 테두리, 계단식 입체 버튼, 본문 도트 폰트,
  원색 단색 대면적

## S1. 로그인 ✅

- 닉네임 1필드 (1~12자, 정책 세부 미정) + [시작하기]
- `POST /session` → user id + token 발급 → **token을 localStorage 저장**
- 재방문: token 있으면 이 화면 건너뛰고 메인 직행
- **재방문 판정 (2026-07-10 확정)**: 앱 시작 시 localStorage token 유무 확인 →
  있으면 서버 검증 후 메인 직행, 없으면 로그인 화면
- **닉네임 중복 허용** (식별은 token). 다른 기기 = 다른 계정 — MVP 감수
- 확장 예약: 복구 코드 (users.recovery_code 컬럼 하나로 추가 가능)

  - 아바타 생성 중: 패널에 졸라맨 + "아바타 생성 중 · 예상 N분" 표시,

- **아바타 강제 안 함 (2026-07-10 확정)**: 아바타를 안 만든 유저도 졸라맨으로

  (졸라맨 = is_system 아바타 에셋). 아바타·에셋 동일 테이블 확정
- **아바타 제작과 에셋 제작은 별도 화면** (통합 스튜디오 안 함 — 2026-07-10 확정)

## S2b. 내 창고 ✅

- **진입**: 메인 [내 창고] 버튼, 또는 아바타 패널 클릭(→아바타 탭)
- **2단 구조 (2026-07-10 확정)**: 큰 2분류 탭 [아바타] / [컴포넌트 에셋].
  컴포넌트 탭 내부에 카테고리 소필터(플랫폼/장애물/몬스터/배경)
- 썸네일 그리드로 나열. 상단에 "내가 만든 에셋 N개" 통계(가벼운 수준).
  "기본 제공 / 내가 만든" 구분은 is_system 플래그로 판정
- **생성 상태 표시 (썸네일 오버레이, 2026-07-10 확정)**:
  - queued = "대기 중 · 예상 N분"
  - generating = "생성 중 · 남은 시간 ~N분" (프로그레스)
  - ready = 정상 썸네일
  - failed = 붉은 뱃지 + [다시 시도]
  - 미완성 에셋은 사용 불가
- **예상 대기 시간**: 큐 위치 + 최근 평균 생성시간(이동평균) 조합, 표시는 여유 있는
  범위("약 2~4분")
- **상태 갱신**: Socket 푸시 우선(이미 Socket.IO 사용), 폴링은 대안. [미확정으로 표기]
- 썸네일 클릭 → **에셋 상세/검수 팝업**(아래 공통 컴포넌트)

  자동 결정)
- **액션별 [🔄 재생성] 버튼**. [그림·속성 수정하기]→스튜디오로 원본 로드

## A. 아바타 생성 ✅

레이아웃: 좌측 도구 패널 + 중앙 캔버스 + 하단 설명 입력/생성 버튼.

- **캔버스**: 1×2 타일 비율, 편집 해상도 256×512, 투명 배경.
  가이드라인·안내 문구 없음 (허리선은 그리기 전에 알 수 없고, 키 보정 안내는 불필요 — 2026-07-10)
  - **캔버스 배경(투명 표시)**: 무채색 회색 2톤 체커보드(#d4d4d4/#bfbfbf, 16px).
    테마 색을 캔버스 안에 쓰지 않는 이유: 색 인지 왜곡 방지.
    밝은/어두운 체커 토글 버튼 제공 (흰색 그림 대비용)
  - **캔버스 격자**: 인게임 1타일 경계 = 진한 실선(#808080), 각 타일 내부 2×2
    4분할 = 점선(#a6a6a6). 아바타 캔버스(1×2)는 중앙 실선 1개 + 타일별 점선 십자
  - 격자·체커는 그리기 레이어와 분리된 **표시 전용 오버레이** — 스포이드가 찍지
    않고, 제출물에 포함되지 않음
  - 이 캔버스 사양은 에셋 스튜디오와 공통
- **도구** (2026-07-10 확정): 펜 / 지우개 / 굵기 / 스포이드(RGB만 —
  불투명도 슬라이더는 건드리지 않음, 혼란 방지) / 전체 이동(부분 선택 이동 없음)
  / 실행취소(이동 작업 포함) / 전체지우기
  - 전체 이동은 제출 시 정규화(중앙+바닥 스냅) 때문에 최종 결과에 영향 없음 —
    그리는 중 구도 편의 기능
- **팔레트**: iOS 스타일 음영 그리드 (회색조 1행 + 색상×명도 그리드 ~120칸)
  + 불투명도 슬라이더 + 최근 사용 색. 자유 스펙트럼 없음
- **이미지 업로드 없음** (2026-07-10 확정) — 제거 이유:
  ① 배경 제거(ML) 파이프라인 갈래 삭제 (그림판 그림은 항상 투명 배경),
  ② 저작권·부적절 이미지가 멀티플레이 화면에 노출되는 리스크 차단 (검수 시스템 없음),
  ③ 손그림 스타일 일관성.
  클립보드 붙여넣기(Ctrl+V)도 paste 이벤트 차단으로 함께 봉쇄
- **캔버스 밖 보존**: 내부 작업 버퍼를 보이는 캔버스(256×512)의 3×3배(768×1024)로
  두고, 이동으로 캔버스 밖에 나간 픽셀은 버퍼에 보존 (다시 옮기면 복원).
  밖 영역은 어둡게 딤 처리해 표시. 제출 시 보이는 영역만 크롭
- **내 아바타 섹션** (도구 패널 하단): 내가 만든 아바타 썸네일 나열
  - [장착]: 생성 완료된 아바타를 재생성 없이 즉시 전환 (avatar_asset_id 변경)
  - [불러와서 수정]: source_image를 캔버스에 로드 → 생성 시 새 아바타 행 추가
  - 이전 아바타는 삭제하지 않고 보관 (스키마 변경 없음)
- **설명 입력** (선택): LLM 프롬프트 원료
- **[생성하기]**: `POST /assets` (category=avatar) → **즉시 메인으로 복귀**,
  진행 상태는 메인 아바타 패널이 표시. 이 화면은 제출까지만 책임
- **정규화 (서버, 제출 시)**: 불투명 bbox를 가로 중앙 정렬 + 바닥 스냅.
  공중부양 표현은 그림(구름·그림자 포함) 또는 설명→AI 모션으로 —
  부양 오프셋 연출은 시각-판정 괴리 때문에 만들지 않음 (2026-07-10 확정)
- 재생성 UI는 전체 재생성만 노출 (액션별 개별 재생성은 스키마상 가능하나 미노출)

## B. 에셋 스튜디오 ✅

- 그림판 도구·팔레트·캔버스 밖 보존·업로드 없음 = 아바타 화면(A)과 공통
- 캔버스 격자·체커 = A의 공통 캔버스 사양을 따름. 단 캔버스 비율은 선택한 크기
  n×m을 따름
- **결정 확정 (2026-07-10 확정)** (기존 미확정 5건 해소):
  - ① 캔버스-크기 관계: **자유 변경** (그리는 중 언제든 n×m 조정, 그림 리샘플)
  - ② 생성 후 속성 수정: 검수 뷰의 [그림·속성 수정하기]로 처리
  - ③ "남이 만든" 에셋: 좌측 [에셋 불러오기]로 (아래)
  - ④ 애니메이션: 카테고리+옵션이 필요한 액션을 **자동 결정·생성**
    (유저가 개별 토글 안 함)
  - ⑤ 이름: **필수**
- **레이아웃 (2026-07-10 확정)**:
  - **좌측 패널 = 도구 + 팔레트 + [에셋 불러오기]** (세로로 쌓임,
    "내 창고" 사이드바는 제거)
  - **우측 패널 = 카테고리 + 크기(가로 n · 세로 m) + 속성**
    (asset-attributes.md의 [택1] 라디오/체크박스/프리셋 셀렉트)
  - **가운데 = 캔버스** (남는 공간 자동 확보)
- **[에셋 불러오기] 동작 (2026-07-10 확정)**: 누르면 모달에 "내가 만든 / 남이 만든"
  탭 구분 표시 → 선택해 캔버스+속성 로드 → **반드시 수정해야 저장 가능**
  (그대로 복제 저장 불가)
- **패널 리사이즈 (2026-07-10 확정)**:
  - 접기 버튼은 패널의 안쪽 테두리 중앙에: 좌측 패널→우측 테두리 중앙 ◀,
    우측 패널→좌측 테두리 중앙 ▶
  - 접히면 화살표가 반대 방향으로 뒤집혀 화면 가장자리에 얇은 탭으로 잔류,
    누르면 다시 펼침
  - 가로 리사이즈: 패널의 안쪽 테두리를 드래그(접기 버튼 영역 피해서 위/아래 구간이
