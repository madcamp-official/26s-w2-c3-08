# 시각 언어 (테두리·오라·오버레이) — 가독성 시스템

> 2026-07-14 확정. 유저가 에셋 그림을 자유롭게 그리므로 **생김새만으로는 역할(충돌·위험·기능)을 못 읽는다.**
> 이를 **테두리·발광·모션이라는 별도 시각 언어**로 보완한다. 이 언어는 스프라이트에 굽지 않고 **런타임 오버레이**다.
>
> **2026-07-15: §1·§2 전체 구현 완료.** 파생 = `shared/visual/deriveVisualTags(FromSpec).ts`,
> 렌더 = `client/src/rooms/baseworld/visualLanguage.ts`(BaseworldScene에서 분리) + `BaseworldScene.drawVisualLanguage()`.
> §2(맥락 표시)는 **근접(거리 페이드) OR 마우스 hover** 중 큰 쪽을 노출도로 사용(`tuning.json`의 `visual.revealNearPx/FarPx`).
> 실사용 확인으로 원안에서 바뀐 점: 무적 시 "주황" 대신 **흰색**(안전 의미 재사용, 색 개념 안 늘림) ·
> 스위치 토글러는 50:50 균등 대신 **현재 상태 색이 둘레 대부분을 차지**하는 비율 회전 ·
> 몬스터 vuln.stomp(가시 등)의 반격은 실제 게임 로직이 없어 위험색 미표시(구현되면 재반영).

## 원칙

- **파생 규칙화**: `deriveVisualTags(category, attrs, faceInfo) → { 면별 테두리, 오라/틴트, 표면 오버레이, 텔레그래프 }`.
  `deriveActions`와 같은 방식으로 **shared에 단일 소스**로 두고, **클라 렌더(Phaser)와 맵 에디터 미리보기가 같은 함수를 사용** → "만들 때 본 대로 플레이된다."
- **스프라이트 불변**: 시각 태그는 그림 위 오버레이. 원본 시트(AssetSprite)는 안 바꾼다.
- **2단 노출**: 너무 많이 동시에 켜면 화면이 정신없으므로,
  - **항상 표시** = "몰라서 죽는 것" 방지 최소셋(충돌·위험·소속·스위치·아이템).
  - **맥락 표시** = 표면 효과·모션 텔레그래프·상태 카운트 등은 **근접 / 마우스 오버 / 에디터**에서만.

## 1. 항상 표시 (기본)

### 1.1 면별 테두리 (충돌 + 위험)
플레이어·에셋 모두 면(top/bottom/left/right) 단위로:

| 면 상태 | 표시 |
|---|---|
| 단단한 면(충돌) | **흰 실선** |
| 통과 가능한 면 | **점선** (반통과: 위 실선 + 통과쪽 점선) |
| 대미지 주는 면 | **빨강**(즉사 구분 없음 — HP 1/2 모델이라 모든 대미지가 치명) |
| 무적 상태의 대미지 면 | **주황**(빨강이던 면이 주황으로) |
| 넉백 범퍼·밀쳐냄(무해) | **파랑/청록 실선**(빨강 아님 — 밀지만 안 아픔) |
| 트램펄린 윗면(몬스터·**블록 공통**, 2026-07-15 보강) | **초록/스프링**(밟으면 튕겨 이득) |

- **몬스터 기본**: 접촉 대미지(true)면 **위 빼고 전부 빨강**(윗면은 밟기 가능). ⚠️ 밟기 반응이 가시(spiky)여도 실제 반격 로직이 없어(2026-07-15 확인) 윗면은 여전히 밟기 가능 표시. **무적(immortal)** 은 표시 안 함(빨강→주황은 "플레이어가 지금 무적"일 때만, §아래 참조).
- **장애물**: `contactEffect`의 `zone`(all / except_top / bottom_only)에 따라 **대미지 주는 면만 빨강**.
- **플랫폼**: 대미지원이 아니므로 흰 실선/점선만(충돌 방식 `full`/`top_only`/`faces`에서 파생).

### 1.2 소속 · 특수
| 대상 | 표시 |
|---|---|
| 내 아바타 | **흰색 테두리**(2026-07-15 반전 — 원안은 회색이었음) |
| 다른 플레이어 | **회색 테두리** |
| 스위치 토글러(시스템 ON/OFF 블록) | **빨강·파랑 반반 테두리가 회전** |
| 스위치 영향 블록(`switch_on`/`switch_off`) | **빨강·파랑 틴트** + 현재 스위치 상태(실체/유령) |
| 아이템 주는 에셋 | **노란 발광** |
| 아이템 | 노란 발광 + **스프링 확대·축소 펄스** |
| 배경 에셋 | 뒤 레이어 + 딤, **테두리 없음**(충돌 없음을 명확히) |

## 2. 맥락 표시 (근접 / 마우스 오버 / 에디터)

- **표면 효과**: 컨베이어 = 방향 화살표 · 미끄러움(얼음) = 서리/광택 · 바운시 = 윗면 바운스 화살표 · 대시 = 스피드 라인 · 낙하/파괴 반응 = 밟는 순간 **금 가기 + 흔들림**(곧 무너짐).
- **모션 텔레그래프**: 이동(patrol/ride/spin/pendulum) = 경로·방향 고스트 · 돌진(charge) = 발동 직전 **번쩍** · 주기/점멸(periodic/blink) = 리듬 페이드 · 근접(proximity) = 접근 시 **경계 발광** · ride_start = "밟으면 출발" 힌트.
- **상태·카운트**: HP 2~3 몬스터 = 남은 히트 핍 · 분노(enrage) = "밟으면 분노" 경고 · 분열(splitOnDeath) = 갈라짐 암시 · 발사(shooter) = 발사구 표시.
- **숨은 블록(hidden)**: 플레이 중 **비표시**(원작처럼 서프라이즈), **에디터에서만 유령**.

## 스위치 (전역 · 라인 단위)

- SMM2 ON/OFF 스위치식: **누가 하나 토글하면 라인 전역의 대상이 동시 반응**(짝짓기 linkKey 불필요).
- **토글러 = 옵션**(유저 에셋에 붙는 "접촉 시 라인 스위치 토글" 속성 — **시스템 블록 아님**). `switchToggle` 물성과 연결. **토글 방식 SMM2 동일**(어느 방향에서 맞거나 밟으면 토글). **상태 = 라인당 boolean 1개·OFF 시작·서버 권위**, 토글러 여러 개면 전부 같은 스위치 공유.
- "영향받는" 쪽은 기존 옵션 재사용(`switch_on`/`switch_off`, 장애물 `trigger:switch`). **토글 옵션만 스키마에 신규 추가 필요.**
- ⚠️ 디바운스(접촉 중 매 틱 토글) 문제는 "클라 즉시 표시 + 서버 쿨다운" 패턴으로 **나중에 일괄** 처리(스위치 외 다수 공통).
