# 에셋 속성 시스템 설계 초안

> 유저가 에셋 제작 시 선택하는 속성(특수사항) 목록.
> SMM2 전 파츠(약 213종, `smm2_parts_catalog.tex` 참조)의 동작을 역산해 도출.
>
> **출처 표기**
> - `[원작]` — SMM2 파츠 동작을 그대로 옵션화 (괄호 안이 근거 파츠)
> - `[원작+수치화]` — 원작 동작이되, 원작은 고정값인 것을 수치 입력으로 확장
> - `[자체]` — 원작에 없는 우리 추가 (출처 병기)
>
> **표기 규칙**
> - `[택1]` 그룹: 상호 배타. UI에서 라디오 버튼
> - 그 외: 독립 조합 가능. 체크박스(T/F)
>
> **수치 정책 (2026-07-10 확정)**: 자유 수치 입력은 두지 않는다.
> 본문의 `n`은 전부 **3단 프리셋 enum**으로 노출·저장한다 (원작 SMM2 방식과 동일).
> - 속도 n → `slow / normal / fast`
> - 주기 n → `short / normal / long`
> - 감지 거리 n → `near / normal / far`
> - 반발력 n → `low / high`
> - 생명력 n → `1 / 2 / 3`
> - 낙하 지연·재생 시간 → 고정 상수 (기획서: 낙하 2초, 재생 3초)
>
> **예외 — 크기**: 에셋 크기는 타일 단위 `가로 n × 세로 m` **수치 입력 허용**
> (2026-07-10 결정). 상한 필요 (예: 1~8). 단 **플레이어는 1×2 고정**
> (`player-spec.md` 참조).
>
> 실제 물리값 매핑(예: fast=160px/s)은 DB가 아닌 게임 상수 테이블에서 관리한다.
> 스키마 연계는 `db-schema.md` 참조.

> 경사 타일과 다른 충돌 타일의 그리드 겹침 금지 (겹치면 순간이동 버그).

### [택1] 접촉 반응 (2026-07-10 개정)
| 옵션 | 출처 |
|---|---|
| 없음 (기본) | — |
| 닿으면 2초 후 낙하 → 5초 후 재생 (고정) | [원작+자체] (도넛 블록 + 재생은 기획) |
| 닿으면 2초 후 파괴(소멸) → 5초 후 재생 (고정) | [자체] (기획) |

**+ 감지 면 체크 (중복 가능, 접촉 반응 ≠ 없음일 때)**: 상 / 하 / 좌 / 우.
기본값 = 상면만 (원작 도넛 블록의 "밟으면"과 동일).
구현: Phaser `body.touching` 면 정보와 대조 — 장애물의 접촉 판정 부위와 코드 공유.

> **플레이어에 의한 직접 파괴(타격 파괴)는 제거** — 유저 제작 에셋 + 다수 동시
> 플레이 + 라인 랜덤 연결 특성상, 영구 파괴는 뒷순번 플레이어의 진행 불능
> (소프트락)을 만들 수 있어 변수가 너무 많음.
> 같은 이유로 **재생은 T/F 옵션이 아니라 항상 재생(고정)**.

충돌 없는 순수 장식. z축 뒤에 렌더링. 유저 제작 대상.

## 5.5 조합 검증 — 원작 파츠 재현 레시피

속성 체계가 원작을 표현할 수 있는지 확인용 예시.

| 원작 파츠 | 카테고리 | 조합 |
|---|---|---|
| 쿵쿵 | 장애물 | 접촉=대미지(부위=상면 제외), 트리거=접근 감지(x축), 동작=감지 시 돌진(아래)→복귀. 압사는 엔진 전역 규칙이 처리 |
| 고드름 | 장애물 | 접촉=대미지(부위=하면만), 트리거=접근 감지(x축), 동작=감지 시 돌진(아래)→재생성 |
| 파이어바 | 장애물 | 접촉=대미지, 트리거=상시, 동작=제자리 회전 |
| 스큐어 | 장애물 | 접촉=즉사, 트리거=주기, 동작=돌출/후퇴 |
| 도넛 블록 | 플랫폼 | 윗면만 충돌, 접촉 반응=2초 후 낙하(5초 재생) |
| 얼음 블록 | 플랫폼 | 완전 충돌, 미끄러움 |
| 리프트 | 플랫폼 | 반통과, 경로 왕복 |
| 굼바 | 몬스터 | 보행, 추적 안 함, 절벽 낙하, 밟기=즉사 |
| 가시돌이 | 몬스터 | 보행, 추적 안 함, 밟기=불가 |
| 부끄부끄 | 몬스터 | 부유, 시선 반응, 밟기=불가 |
| 검은 뻐끔 | 몬스터 | 고정, 불사, 접촉 대미지 |
| 해머 브로 | 몬스터 | 보행(제자리), 발사체(포물선), 주기 도약 |

## 6. MVP 권고

- 1차 노출: 각 [택1] 그룹의 상위 2개 옵션 + 기획서 유래 독립 옵션
  (낙하/재생, 생명력, 감지 거리, 접촉 즉사, y축 감지 낙하, 주기 돌출)

- 배타 그룹은 UI에서 라디오, 조건부 비활성(불사→생명력 회색 처리 등)을 스키마에 명시
