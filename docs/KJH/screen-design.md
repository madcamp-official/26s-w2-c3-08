# 화면 설계 (진행 중)

> 2026-07-10~14 세션에서 화면별로 확정해가는 작업 문서.
> 팀원 PPTX 초안(S1~S4)을 참고 삼되, 확정 사양은 이 문서가 기준.
> 전체 플로우: 로그인 → 메인 → (아바타 제작 / 에셋 스튜디오) → 로비 → 방 → 제작 → 검증 → 레이스 → 결과

## ⚠️ 문서 상태 — 반드시 먼저 읽기 (2026-07-14)

- **API 스펙은 전부 미정입니다.** 엔드포인트·요청/응답 형태가 확정되지 않았습니다. 화면을 먼저 만들되 **서버 연동부는 인터페이스로 추상화**하고, 실제 경로·페이로드를 **하드코딩하지 마십시오.** (확정되면 이 문서에 반영)
- **타일당 px(tileSize)는 바뀔 가능성이 높습니다.** 모든 길이·간격·크기는 **`tileSize` 기준 상수/비율**로 표현하십시오. px 하드코딩 금지 — 한 곳만 바꿔도 전체가 따라오게.
- 본문 곳곳의 **`[미확정]`** 태그 = 아직 확정 안 된 항목. 구현 시 가정을 두되 바뀔 수 있음을 전제.
- **디자인 참고**: *Super Mario Maker 2(슈마메2)* 유튜브 플레이 영상을 보며 UI·연출 톤을 참고해 주세요. 단 아래 "UI 테마/모션" 원칙(성숙하게 렌더링)을 기준으로.

## UI 테마 (2026-07-10 확정)

- **원칙**: "SMM2의 색과 격자 모티프를, 콘솔 런처의 그라데이션 질감으로 성숙하게
  렌더링". 유아스러운 표현(두꺼운 검정 아웃라인, 전면 도트 폰트, 원색 단색 면)은
  금지
- **색 배치 (SMM2 박스아트 기반)**:
  - 건설 노랑 `#F6BE00` = 주역 (타이틀 밴드·주요 버튼·활성 상태)
  - 스카이 블루 `#4A9DE0` 계열 = 배경 (수직 그라데이션)
  - 마리오 레드 `#E52521` = 포인트 (위험 액션·강조 숫자)
  - 지형 그린 `#43A047` · 흙 브라운 `#8B5A2B` = 보조
  - 정확한 hex는 구현 시 조정 가능한 기준값
- **질감**: 색면은 은은한 수직 그라데이션 + 부드러운 광택. 모서리는 살짝만 라운드.
  배치는 크고 밀도 있게 레이어드
- **타일 오버레이 (도트 감성의 핵심 장치)**: 면적 있는 색면(타이틀 밴드, 배경,
  큰 버튼) 위에 아주 투명한 흰색 선(rgba(255,255,255,0.08) 안팎)으로 타일 격자
  패턴을 일관 적용. 격자 크기는 인게임 타일과 호응(요소 크기에 따라 24~32px급).
  박스아트의 하늘 격자 모티프를 UI 전체 패턴 언어로 확장
- **폰트 이원화**: 타이틀·타이머 숫자 등 포인트 = 도트/블록형(Galmuri 큰 사이즈,
  OFL) / 본문·버튼·폼 = Pretendard
- **금지 목록**: 두꺼운 검정 픽셀 테두리, 계단식 입체 버튼, 본문 도트 폰트,
  원색 단색 대면적

## UI 모션·마이크로인터랙션 가이드 (2026-07-14 신규)

> 원칙: **선형(linear) 이동 금지** — 모든 등장·반응에 스프링/이징. 위 UI 테마("성숙하게 렌더링")와
> 맞춰 **생동감 있되 유아스럽지 않게.** 과하지 않게, 일관되게.

- **등장**: 버튼·카드·패널이 뜰 때 아래→위로 **스프링 오버슈트**(살짝 튀어올랐다 정착).
  여러 요소가 동시에 뜨면 **스태거**(0.03~0.06s 간격 순차 등장)로 리듬.
- **호버**: 미세 확대(scale 1.02~1.05) + 은은한 광택/그림자 상승.
- **클릭**: 눌림(scale ~0.94) → **스프링 복귀로 "띠용"**(오버슈트 바운스) + 색·그림자 짧은 펄스.
- **화면 전환**: 페이드 + 슬라이드를 **이징(cubic-bezier, 선형 아님)** 으로.
- **상태 모션**: 생성 중 프로그레스·타이머 등 진행감 있는 미세 모션.

**구현 원칙 (전문 방식)**:
- **모션 토큰화**: 컴포넌트마다 즉흥값 말고 **공통 토큰 세트**를 정해 일관 적용
  (예: `spring.pop = { stiffness: 500, damping: 28 }`, `ease.enter = cubic-bezier(0.22, 1, 0.36, 1)`).
- **접근성**: `prefers-reduced-motion` 존중 — 모션 최소화 대체 경로 제공.
- **라이브러리**: 우리 클라가 React+Vite라 **framer-motion**(선언적 스프링·레이아웃 애니메이션) 또는
  react-spring 권장. 선택은 팀원 재량 `[미확정]`.

## 게임 규칙 (레이스) (2026-07-14 신규)

> ⚠️ 아래 수치·규칙은 기획 확정분이나 **밸런싱으로 조정될 수 있음.** 모든 길이/시간은 상수로.

### 방 (S3 로비 → C 방 대기실)
- **방 생성**: 공개방 / 비밀방. 비밀방은 **비밀번호 설정** 필요. 그 외 설정 없음.
- **입장**: 공개방 목록에서 입장, 또는 비밀방 비번 입력.
- **난입**: 맵 제작 페이즈 동안 언제든 다른 플레이어 난입 가능.
  단 **제작시간 1분 미만** 남은 시점에 난입하면 그 플레이어는 **맵 제작 불가**(대기/관전).

### 제작 페이즈 (3분)
- 각 플레이어가 **자기 라인 1개**를 제작.
- **사용 에셋 제한**:
  - **내가 만든 에셋**: 카테고리 무관 **최대 3개**.
  - **DB(공용) 에셋**: 카테고리별 정해진 개수만큼 **랜덤 제공**.
  - **배경 에셋**: 예외 — **제한 없음, 자유 사용.**
- **프리뷰 = 별도 화면 아님(2026-07-16 변경)**: 제작 페이즈 시작 시 **맵 에디터 위에 공용 에셋 안내판이 오버레이로 뜸**(자동 타임아웃 없이 클릭하면 사라짐) — 상세는 S4 "공용 에셋 안내판" 참조. `GAME_RULES.previewSec` 상수는 유지되나 화면 전환용이 아니라 안내판 표시 관련으로만 쓰일 수 있음 `[구현 시 재검토]`.

### 라인·깃발
- **라인 최대 길이 고정**(상수). 실제 길이는 시작/끝 깃발 위치로 **유동 결정.**
- 깃발 = **마리오 체크포인트식.** 에디터 열면 **미리 대충 배치**돼 있음.
- 깃발 아래 **3×1 바닥 = 깃발과 한 세트**(항상 붙어 다님).
- **끝 깃발은 시작 깃발보다 왼쪽 불가.** 둘 다 가로·세로 자유 이동.
- 기본 **완전 빈 공간**, 두 깃발 아래 3타일만 기본 땅.
- **테스트**: 라인을 **1회 이상 테스트 완료 못 하면 그 라인은 맵에 안 쓰임.**
  **가장 최근 완료된 테스트 라인**이 사용됨.

### 병합·골
- 제작 종료 후, **테스트 완료된 라인끼리 랜덤 순서로 연결.**
- **맨 첫 라인의 진짜 시작 / 맨 끝 라인의 진짜 골** 깃발만 **깃대를 길게**(구분).
- 마지막 라인 끝에 **골 지점.**

### 레이스
- **게임 시간 = 라인 수 × 40초.**
- 먼저 **골대를 잡은 사람이 1등.** 1등 도달 시 **10초 카운트다운** → 그 안에 들어온 사람은 **순서대로 순위**, 나머지는 **리타이어.**
- 게임 시간 종료까지 1등이 안 나오면 → **30초 "라스트댄스"** → 30초 뒤 **가장 앞선 순서로 1/2/3등만** 순위.
  - 라스트댄스 동안 **1/2/3위 머리 위에 금/은/동 긴 세로선**(직관적 판단).
- **라인 파괴 스윕**: 게임 시간 동안 **첫 라인부터 순차로 50초마다** 그 라인의 모든 에셋이 파괴되고
  시작·골 지점 땅이 쭉 이어짐(**라인 제작자가 유리해지는 것 방지**).

### 라인 저장 (백엔드)
- 라인은 **테스트 성공 시 영속 저장**(MapLine 엔티티, `[미확정 — 스키마 설계 중]`).
  나중에 "라인 카테고리"로 남의 라인 재사용 대비.

## S1. 로그인 ✅

- 닉네임 1필드 (1~12자, 정책 세부 미정) + [시작하기]
- `POST /session` → user id + token 발급 → **token을 localStorage 저장**
- 재방문: token 있으면 이 화면 건너뛰고 메인 직행
- **재방문 판정 (2026-07-10 확정)**: 앱 시작 시 localStorage token 유무 확인 →
  있으면 서버 검증 후 메인 직행, 없으면 로그인 화면
- **닉네임 중복 허용** (식별은 token). 다른 기기 = 다른 계정 — MVP 감수
- 확장 예약: 복구 코드 (users.recovery_code 컬럼 하나로 추가 가능)

## S2. 메인 ✅

- **버튼 구성 (2026-07-10 확정)**: [게임하기]→로비 / [에셋 만들기]→에셋 스튜디오 /
  **[내 창고]→창고 화면(S2b, 신규)** / **우측 구석 톱니(⚙️) 아이콘→설정 모달(S2c, 신규)**
- 좌: **아바타 패널**
- **아바타 패널 단순화 (2026-07-10 확정)**: "장착된 아바타 표시 + 클릭 시
  [내 창고]의 아바타 탭 열기"로 일원화. 아바타 검수는 창고(S2b)에서 처리
  - 미보유 유저: 시스템 기본 아바타 "졸라맨" 표시
  - 아바타 생성 중: 패널에 졸라맨 + "아바타 생성 중 · 예상 N분" 표시,
    완료 시 자동 갱신 (아바타 한정 지름길 요약 표시)
- **아바타 강제 안 함 (2026-07-10 확정)**: 아바타를 안 만든 유저도 졸라맨으로
  게임 플레이 가능
- **아바타 = 에셋 (Q2 해소, 2026-07-10 확정)**: 아바타 = category='avatar'인 에셋
  (졸라맨 = is_system 아바타 에셋). 아바타·에셋 동일 테이블 확정
- **아바타 제작과 에셋 제작은 별도 화면** (통합 스튜디오 안 함 — 2026-07-10 확정)

### 레이아웃 확정 (2026-07-16)

컨셉: **화면을 꽉 채우는 직사각형 영역들의 배치, 빈 공간 없음.** 버튼식·둥근 테두리 지양(기본 상태는 각짐).

```
┌─────────────────────────┬───────────────────────────┐
│      {닉네임}의 아바타       │                            │
│                          │         게임하기             │
│                          │                            │
│      아바타 미리보기          ├───────────────────────────┤
│      (영역 전체 채움)         │                            │
│                          │        에셋 만들기            │
│  [idle][walk][onAir]     │                            │
│  (하단 테두리에 박힌 작은 탭)  ├───────────────────────────┤
│                          │                            │
│                          │         내 창고              │
│                          ├───────────────────────────┤
│                          │  설정 (압도적으로 얇은 띠)      │
└─────────────────────────┴───────────────────────────┘
   좌측 45%                      우측 55%
```

- **좌측 패널(45%)**: 상단 중앙 "{닉네임}의 아바타" 라벨 → 아바타 미리보기(영역 전체 채움, 작은 박스 아님).
- **idle/walk/onAir**: 좌측 패널 **하단 테두리에 박힌** 작은 탭(가로:세로 = 1:1.5 비율, 둥근 모서리+흰색 낙서 테두리는 **기본 상태부터 항상** 있음 — 아래 "인터랙션 공통 규칙"의 대형 타일과 다름).
  - **물리 스위치 동작**: 클릭 시 기존 `switch` 효과음(재활용) 재생 + 클릭한 탭이 아래로 눌리며 해당 액션이 미리보기에 재생. **상호배타** — 다른 탭 클릭 시 이전에 눌려있던 탭은 위로 튀어 올라옴(해제). 눌린 상태에서도 라벨 텍스트는 순간 위로 떠올라 항상 보이게.
- **우측 패널(55%)**: 게임하기 / 에셋 만들기 / 내 창고 — 각각 폭 전체를 채우는 가로 바 3줄 스택. 맨 아래 **설정**은 압도적으로 얇은 띠(다른 3줄 대비 눈에 띄게 얇음), 좌측 아바타 패널 쪽으로는 안 넘어감(우측 패널 폭 안에서만).

### 인터랙션 공통 규칙 (대형 타일: 게임하기/에셋만들기/내창고/설정)

1. **기본**: 영역 전체를 각진 테두리로 채움. 장식 없음.
2. **호버**: 영역이 안쪽으로 살짝 축소(여백 발생) → 그 축소된 형태에서 각진 테두리가 둥글어지며 **흰색 손그림(낙서) 테두리**가 나타나 지글지글(계속 다시 그려지며 흔들림).
3. **클릭**: 낙서 테두리 사라짐 → **세로로 먼저 길어짐** → 이어서 커튼 전환 효과.

(idle/walk/onAir 같은 작은 탭은 이 규칙과 별개 — 기본 상태부터 항상 둥근+낙서 테두리, 호버 단계 없이 클릭=스위치 눌림.)

- **가독성(테두리·오라)**: 유저 그림만으론 역할을 못 읽으므로 **면별 테두리·오라·오버레이 시각 언어**를 런타임 적용 — 상세는 [visual-language.md](visual-language.md). 에디터 미리보기도 같은 규칙(`deriveVisualTags`).

### 인터랙션·레이아웃 확정 (2026-07-16, 기록만 — 미구현)

**메인 화면과 다른 점(변형 규칙)**:
- **창고 카드 [+ 즐겨찾기] 버튼**: 모서리(X 닫기 쪽)가 아니라 **카드 중앙**에 뜨도록 변경.
- **우측 툴바**: 도구 버튼 완전 삭제. 대신 **좌클릭/우클릭/동시누름/스크롤 조작법을 그림과 함께 상시 안내**하는 패널로 교체. **현재 장전(선택)된 에셋 이름도 여기 표시.**
- **즐겨찾기 패널 선택 상태**: 선택된 카드는 **지글지글 낙서 테두리 유지**(호버 아님, 선택 지속 중 계속). **단일 선택**만 가능 — 다른 카드 선택 시 이전 것 자동 해제, 이미 선택된 카드를 다시 클릭하면 선택 해제.
- **시간단축/시간추가/테스트하기/좌측패널 버튼**: 메인 화면과 동일한 공통 규칙(꽉 찬 각진 기본 → 호버 시 축소+테두리 생성+지글지글 → 클릭 시 테두리 소멸→세로로 늘어남→커튼).

**맵 캔버스 입력**:
- **좌클릭**: 선택 / 배치 / 드래그로 경로(patrol·ride 끝점) 설정.
- **우클릭**: 삭제.
- **좌우 동시**: 캔버스 이동(팬). 좌/우 단독 클릭과 충돌 방지를 위해 **클릭 즉시 반응하지 않고 짧게 대기** — 그 사이 반대쪽 버튼도 눌리면 단독 동작(선택/배치/삭제)을 취소하고 팬으로 전환.
- **스크롤 줌**: 현재 즉시 스냅 방식 → **보간해서 부드럽게** 변경.
- **기본 격자**: 40×20 → **25×12**로 축소. **게임 규칙 자체 변경**(`GAME_RULES.lineMaxWidthTiles` 25, `lineMaxHeightTiles` 12) — 기존 테스트 라인 `test.gap`(폭 28)이 새 상한을 넘으므로 폭 25 이하로 조정 필요.

**시간조정(시간단축/시간추가) 메커니즘**:
- 클릭 1회당 **30초** 증감.
- **플레이어당 평생 1회만** — 단축이든 추가든 둘 중 하나를 한 번 누르면 **양쪽 다 즉시 비활성화**(재사용 불가).
- **남은시간 ≤45초일 때 시간단축 비활성화**(단축 시 15초 미만으로 내려가는 것 방지).
- **누구나 사용 가능**(방장 한정 아님).
- **남은시간 <20초**: 텍스트 빨간색 + 흔들림 연출.
- **알림 토스트**: 누군가 시간조정 시 방 전체에 "{닉네임}님이 시간을 {증가/단축}하였습니다."가 남은시간 표시 옆에서 살짝 위로 올라왔다 페이드아웃.
- 서버 구현 방향: `RaceState.MemberState.usedTimeAdjust` 플래그 + `RACE_MSG.adjustTime({direction})` 메시지, building 페이즈 한정, 성공 시 방 전체 broadcast로 알림.

**통합 방향**: 지금은 콘솔 `mapedit` 명령으로 여는 독립 UI 셸(더미 데이터, 룸 연결 없음). 시간조정을 실제로 검증하려면 **대기실이 building 페이즈 진입 시 맵 에디터를 실제 룸과 연결해 마운트**하는 통합이 필요(현재 `WaitingRoomScreen`은 building 이후 페이즈를 텍스트로만 표시 — 아직 미구현).

### 에셋 배치 상세 (2026-07-16)

- **깃발**: 이미지로 생성, 다른 에셋과 시각적으로 크게 안 다름(깃발+3×1 바닥 세트 전부 동일 취급). **물리판정 없음**(순수 마커).
  - 꾹 누르면 흔들흔들+그림자 생기며 "들림" 표시 → 그 상태에서 위치 조정 가능.
  - 규칙 벗어나는 위치(끝<시작 등)로 옮기려 하면 **그냥 막힘**(그 이상 안 움직임, 별도 에러 연출 없음).
- **좌우반전**: 더블클릭. 안내 패널에 표기.
- **기본 상호작용은 배치/삭제뿐.** 특수 옵션(이동경로)만 드래그.
- **연속배치**: 에셋 선택(장전) 상태로 꾹 눌러 드래그 → 지나가는 타일마다 연속 배치(페인트 툴처럼). 경로설정 드래그 중엔 연속배치 없음.
- **배치 미리보기**: 장전 상태로 타일에 마우스 가져가면 반투명 고스트가 **타일 좌측 하단 기준**으로 뜸. 배치 불가(이미 점유)면 **빨강** 반투명, 가능하면 **파랑 필터** 반투명. **격자 밖이면 고스트 자체가 안 뜸**(빨강 아님, 표시 없음).
- **배치/삭제 애니메이션**: 스프링 "띠용" 팝인(배치)/팝아웃(삭제). (모든 애니메이션·이동함수에 스프링 적용은 공동 규칙.)
- **삭제**: 확인 절차 없이 즉시. **연속 삭제도 가능**(연속배치와 대칭, 우클릭 꾹 눌러 드래그).
- **판정 정밀도 차등**: 단일 클릭(드래그 아님)은 타일에 조금이라도 걸치면 반영. **연속 드래그 중**엔 타일 중앙 부근(가장자리만 스치는 정도는 제외)에 닿아야 그 타일이 반영 — 빠른 드래그 시 옆 타일 오염 방지.
- **다중 타일 에셋 겹침 판정**: 앵커 타일 하나가 아니라 **차지하는 타일 전부**를 검사.
- **깃발 배치 불가 구역**: 3×1 기단 + 그 위로 5칸(세로 총 6칸, 폭 3) — 깃대 높이(`FLAGPOLE.poleHeightTiles=5`)와 대응. 다른 에셋을 이 구역에 놓을 수 없음.
- **경사(slope) 배치 미리보기**: 고스트는 **대각선 모양**(실제 형태)으로 표시하되, 배치 가능/불가 판정은 **사각형(bounding box)** 기준.
- **창고→즐겨찾기는 [+] 버튼만.** 드래그는 즐겨찾기 패널 **내부 순서 재정렬 전용**(기존 dnd-kit) — 창고 카드에서 즐겨찾기로의 드래그 추가는 없음.
- **창고 검색 기능**: 삭제(오너 토글+카테고리 필터만 유지).

### 이동경로 시각화 — 동작 유형별 (2026-07-16)

- **드래그로 경로 지정 가능한 건 patrol/ride 끝점 하나뿐**(현재 스키마 `MapLinePlacement.endX/endY` 기준). spin·pendulum 반경은 드래그 대상 아니고 속성 패널 프리셋.
- **경로 오버레이(흐리게 표시)는 참고용일 뿐, 배치를 막지 않음**(지형 의존적 경로는 재계산 부담이 커서 강제 안 함 — 2026-07-16 단순화).
  - ride_oneway: 시작점~`endX/endY` 직선 오버레이.
  - spin: `radius` 프리셋 반경의 원 오버레이.
  - patrol/charge: 배치 시점 지형 기준 레이캐스트(벽까지)로 계산한 구간 오버레이 — 지형 의존적이라 참고용.
  - **pendulum**: 반경 파라미터가 스키마에 없어 계산 불가 상태. **`shared/behavior/actions/pendulum.ts`는 이미 `length`(길이)·`amplitude`(진폭)·`periodMs`(주기) 파라미터를 지원**하지만 조립기(`buildRuntimePart.ts`)가 안 넘기고 있어 항상 기본값(2타일·약57도·2.4초) 고정. `spin`과 동일 패턴으로 `BlockAttrs.motion.pendulum`에 `radius: Range3` 추가하면 해소(작은 변경, 미구현 상태로 기록만).

### 에셋 상세정보 표시 (2026-07-16)

- 카드 호버 시 뜨는 정보 위치는 기존 그대로(카드 아래 팝업) 유지.
- **표시 정보**: 이름 / 카테고리 / 크기(가로×세로 타일) / 소유 구분(내가 만든·공용) / 공용 지정 라벨(해당 시).
- **정보 팝업 테두리도 지글지글 낙서 테두리**(항상 켜짐, 라운드 요소 공통 규칙과 동일).

### 배경(background) 배치 (2026-07-16)

- **배치 단위 = 타일 아님, 라인 전체.** 즐겨찾기에서 선택 후 라인 쪽에 마우스를 대면 라인 전체 범위가 하이라이트로 뜨고, **클릭 한 번으로 라인 전체에 설치.**
- **삭제 불가, 덮어쓰기만 가능** — 다른 배경 선택 후 다시 설치하면 기존 것을 교체. 빈 상태로 되돌리는 액션 없음.
- **스키마 해석**: `BackgroundAttrs.size`(w×h)는 라인을 덮는 크기가 아니라 **반복 타일링되는 패턴 한 단위의 크기** — 그 크기의 이미지가 라인 전체에 반복돼 깔림. (기존 스키마 주석에 이 개념이 명시돼 있지 않아 추후 보강 필요.)
- **타일링 기준점 = 시작 깃발.** 반복 패턴의 원점이 시작 깃발이라, **시작 깃발을 옮기면 배경 렌더링이 실시간으로 같이 이동.**
- **격자선 흐림**: 시작 깃발 3타일 기단 왼쪽, 골 깃발 기단 오른쪽(둘 다 플레이 범위 밖) 영역의 격자선은 흐리게 — 플레이 가능 구간과 시각적으로 구분.

### 깃발 간 거리 제약 추가 (2026-07-16)

기존(끝 깃발이 시작 깃발보다 왼쪽 불가)에 더해 — **시작~골 깃발 최소 거리 5타일** 신규 추가.

### 공용 에셋 안내판 (2026-07-16, 15초 프리뷰 화면 대체)

**별도 페이지 아님** — 맵 에디터가 이미 뜬 위에 **오버레이로 띠용 팝인**, **아무 곳이나 클릭하면 띠용 팝아웃**(자동 타임아웃 없음, 클릭 전까진 계속 유지). "아무 곳이나 클릭하면 사라집니다" 안내 문구 포함.

- **공용(랜덤 배정) 에셋만 표시** — 내가 만든 에셋은 안 보여줌(창고/즐겨찾기에서 항상 접근 가능하므로, 이 안내판은 "이번 판에 뭐가 랜덤으로 나왔는지" 확인용).
- **카테고리별로 줄바꿈** + 그 카테고리 대표색 배경 틴트(장치=파랑, 적군=빨강, 아이템=노랑 등, 기존 창고 카드 색 재사용). **카테고리 하나가 카드 개수에 따라 두 줄 이상으로 wrap될 수 있음.**
- **패널 테두리 = 지글지글 낙서 테두리**(팝업·둥근 요소 공통 규칙 — 별도로 안 짚어도 항상 적용).

## D. 검증(테스트) 🔧 — KJH/공용

- 제작 중 **[테스트하기]** 로 자기 라인을 혼자 플레이 테스트. **완주 성공 시** 그 라인이 "테스트 완료"로 저장(최근 성공본만 유효).
- 테스트 1회도 완료 못 하면 그 라인은 **맵에 안 쓰임.**

### 테스트 흐름 확정 (2026-07-16)

- **방식 B 채택**: 저장 없이 **클라이언트가 로컬로 물리 시뮬레이션**(shared 물리 함수 재사용) → 골 도달 성공 시 **그 순간 처음으로 서버에 저장**(`POST /api/lines`, testPassedAt 그때 기록).
  - 서버 측 골 판정 검증 없음(클라 자기 신고) — 이미 만들어둔 `testline` 서버 룸(서버 권위 판정)은 **이 흐름에선 쓰지 않음**(다른 용도로 남겨두거나 폐기 검토 필요).
  - 방식 A(먼저 저장 후 서버 룸에서 검증)를 기각한 이유: 이미 통과한 라인을 재테스트할 때마다 새 라인 행이 쌓이거나 덮어쓰기 API가 별도로 필요해지는 문제.
- **테스트 중 화면**: 전체 화면 전환 아님 — **맵 캔버스 영역만** 게임 화면으로 전환, 캐릭터가 시작 깃발에 스폰. [테스트하기]→[테스트 중단] 버튼 전환. 확대·축소·이동은 계속 가능, 편집(배치/삭제)은 잠김. 중단 시 원복. **격자 표시는 테스트 중 숨김**(실제 게임엔 격자가 없으므로).
- **검증 상태 뱃지**(하단바 근처): 미검증(회색) / 통과됨(초록) / 재검증 필요(주황, 통과 이후 편집함). 통과 순간 캔버스에 짧은 성공 토스트.
