# 개발자 콘솔 · baseworld (2026-07-11)

개발 내내 인게임에서 명령어로 자유 테스트를 돌리기 위한 개발용 콘솔과, 규칙 없이 물리·상호작용만 검증하는 공유 샌드박스 방(baseworld)의 설계 문서입니다.

## 목적

- 개발 내내 명령어로 자유 테스트 — 페이지 이동, 에셋 소환, 물리 파라미터 변경, 샌드박스 진입
- 실사용자 배포 시엔 콘솔을 코드에서 완전히 제거하고 push

## 1. on/off 스위치 — 빌드 시 환경변수 (권장)

- `VITE_DEV_CONSOLE` 환경변수로 제어합니다. `.env.development`=`true`, `.env.production`=`false`
- Vite 빌드 시 `false`면 콘솔 관련 코드가 번들에서 tree-shaking으로 통째 제거됩니다. 실사용자 입장에서 콘솔은 "숨겨진" 게 아니라 "존재하지 않는" 것이며, 번들을 뜯어봐도 나오지 않습니다. 치트 콘솔이 프로덕션에 남지 않습니다.

**대안 비교:**

| 방식 | 즉시 토글 | 코드 잔존 | 실수 위험 | 비고 |
|---|---|---|---|---|
| 빌드 환경변수 (`VITE_DEV_CONSOLE`) | 재빌드 필요 | 제거됨 (tree-shaking) | 낮음 | **권장** — 프로덕션에 코드 자체가 없음 |
| 런타임 플래그 | 즉시 가능 | 클라에 잔존 | 중간 | 뜯어보면 콘솔이 남아 있음 |
| 단순 상수 (`const DEV = true`) | 코드 수정 필요 | 상황에 따라 | 높음 | 끄는 걸 잊으면 그대로 배포됨 |

- **운영**: 평소엔 dev 빌드로 상시 배포해 두고, 실공개 시점에만 prod 빌드로 1회 전환합니다.

## 2. baseworld — 공유 샌드박스 방 (Colyseus TestRoom)

- 콘솔에서 `join baseworld`를 입력하면, Colyseus join-or-create로 항상 같은 이름의 단일 방에 수렴합니다.
- 다른 기기가 같은 배포 서버에서 join하면 자동으로 같은 방에 들어옵니다. 여럿이 실시간으로 상호작용을 테스트할 수 있습니다.
- **규칙 없음**: 타이머·순위·페이즈 없이 물리·밟기·밀기만 도는 그레이박스입니다. 정식 레이스 룸(RaceRoom)보다 먼저 만드는 검증용 방입니다.
- 물리·PvP 개발의 실질적 놀이터입니다. 물리 2차 작업(game feel·밟기·밀기)이 여기서 진행됩니다.

## 3. 명령어 예시 (커스텀 자유)

| 명령어 | 동작 |
|---|---|
| `help` | 사용 가능한 명령어 목록 출력 |
| `goto <page>` | 지정한 페이지/화면으로 이동 |
| `join baseworld` | 공유 샌드박스 방 접속 |
| `spawn <assetId> <x> <y>` | 에셋 소환 (에셋 검증에 직접 사용) |
| `spawn monster <x> <y>` | 몬스터 소환 |
| `tp <x> <y>` | 현재 플레이어 순간이동 |
| `setphysics <param> <value>` | 물리 파라미터 실시간 변경 (물리 검증에 직접 사용) |
| `players` | 현재 방 접속자 목록 |
| `reload` | 클라이언트 리로드 |

- `spawn`·`setphysics`는 에셋·물리 검증에 직접 사용하는 핵심 명령어입니다.

## 4. 구조상 위치

```
client/src/devconsole/
├─ Console.tsx     콘솔 UI (` 키 토글, 입력창+출력로그)
├─ commands.ts     명령어→동작 매핑 (자유 확장)
└─ enabled.ts      import.meta.env.VITE_DEV_CONSOLE 체크 — false면 전체 비활성
server/src/rooms/
└─ TestRoom.ts     baseworld 샌드박스 방
```

## 5. 상시 배포(스테이징)와의 관계

- 서버(VM) + cloudflared 터널로 우리 도메인에 상시 띄워 둡니다. 팀원 누구나 브라우저로 접속해 콘솔을 테스트할 수 있습니다.
- push → VM pull → pm2 등으로 자동 재시작하면 "고치면 배포에 반영"되는 흐름이 됩니다.
- 이 문서는 [architecture.md](architecture.md)의 배포 환경과 연결됩니다.
